# Chandrayaan — Student Web Project

A responsive, interactive educational website about India's Chandrayaan lunar missions, made with **HTML, CSS, and JavaScript**.

## How to run
1. Extract `Chandrayaan_Project.zip`.
2. Open the `Chandrayaan_Project` folder.
3. Double-click `index.html` to open it in your browser.

No installation or server is required. An internet connection is only needed for the optional Google Fonts; the site still works without them.

## Project features
- Responsive layout for desktop and mobile
- Navigation menu that works on small screens
- Interactive mission tabs for Chandrayaan-1, Chandrayaan-2 and Chandrayaan-3
- Timeline of major milestones
- Quick facts section
- JavaScript quiz with feedback
- CSS-created Moon, orbit and lander illustration

## Files
- `index.html` — page content and structure
- `style.css` — styling, layout, responsiveness and CSS illustrations
- `script.js` — mission tabs, mobile navigation and quiz interactions

## Suggested project description
**Title:** Chandrayaan — India's Journey to the Moon

**Objective:** To create an informative and interactive website that introduces the Chandrayaan lunar exploration programme and explains the main milestones of India's Moon missions.

**Technologies used:** HTML5, CSS3 and vanilla JavaScript.

**Conclusion:** This project demonstrates how web technologies can be used to present scientific information in an accessible, responsive and interactive format.

## Accuracy note
This is an educational student project. For official and detailed mission updates, consult the Indian Space Research Organisation (ISRO) website: https://www.isro.gov.in/
